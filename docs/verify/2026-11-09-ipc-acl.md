# 2026-11-09 IPC 管道 ACL 收紧（审计 F1 / 计划 P1a）

改动范围：`crates/winxime-server/src/ipc_server.rs`、`crates/winxime-server/Cargo.toml`。

- 命名管道安全描述符从 `D:(A;;GA;;;WD)`（Everyone、全部权限）改为
  `D:P(A;;GA;;;<当前用户 SID>)(A;;GA;;;SY)`；`P` 屏蔽父对象继承 ACE。
- 取不到当前用户 SID 时退 `D:P(A;;GA;;;OW)(A;;GA;;;SY)`（OW = 对象所有者），**不退回 Everyone**。
- SID 读取或描述符解析失败 → 打错误日志并拒绝启动监听（起不来是可见故障，宽松 ACL 是无声的安全洞）。
- `Cargo.toml` 增开 `Win32_Security`、`Win32_Security_Authorization`（读 token → user SID → 文本）。

新增单测（`ipc_server.rs` 的 `mod tests`）：

- `pipe_sddl_grants_only_current_user_and_system`：SDDL 恰为「用户 SID + SY」，不含 `WD`/`BU`。
- `pipe_sddl_fallback_uses_owner_not_everyone`：无 SID 时「OW + SY」，不含 `WD`。
- `pipe_sddl_is_accepted_by_security_descriptor`：两条 SDDL 均能被 `interprocess` 解析（解析失败 = 服务起不来）。
- `current_user_sid_string_looks_like_a_sid`：真实 token 取到 `S-1-…`，拼出的 SDDL 可解析。
